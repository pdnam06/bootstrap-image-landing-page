# Landing Page với Bootstrap và hình ảnh

GreenTrail là ý tưởng minh họa cho bài thực hành, không phải dịch vụ đặt tour thật.

Mở index.html bằng trình duyệt có Internet để tải Bootstrap 5.3.0 từ CDN.

- Banner tự xây dựng bằng hero-section, container, row; không dùng jumbotron.
- Banner và giới thiệu có hình ảnh SVG cục bộ với img-fluid, alt, width và height.
- Hình minh họa SVG được vẽ riêng cho bài; không cần tải ảnh từ dịch vụ bên ngoài.
- Giới thiệu dùng row với hai col-md-6.
- Bốn tính năng có icon, tiêu đề, mô tả; col-12 col-sm-6 col-lg-3.
- CTA dùng btn-primary btn-lg và dẫn tới nội dung thật trong trang.
- Navbar mở/đóng trên mobile bằng Bootstrap bundle.
